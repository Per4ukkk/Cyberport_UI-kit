# Поле с временем

Поле с временем помогает ввести время с клавиатуры

## Когда использовать

Используйте поле с временем, когда нужно ввести точное время суток. Например, для даты обновления требования

## Описание работы

Когда поле получает фокус, курсор встает в блок с часами

![Иллюстрация из описания компонента](01)

Как только часы заполнены, курсор переходит на минуты.

![Иллюстрация из описания компонента](02)

Когда заполнены и часы, и минуты, поле не теряет фокус.

![Иллюстрация из описания компонента](03)

Если заполнены только часы, то по потере фокуса минуты заполнятся нулями.

![Иллюстрация из описания компонента](04)

Если заполнена только одна цифра минут, то по потере фокуса перед ней ставится ноль

![Иллюстрация из описания компонента](05)
