# Чекбокс

Чекбокс нужен, чтобы управлять параметром с двумя состояниями.

## Когда использовать

Используйте чекбокс для:
- выбора элементов списка. Например, документов для массовых действий;
- выбора параметров. Например, настройки уведомлений.

## Описание работы

Чекбокс выбирается кликом по нему или по названию. Повторный клик снимает выбор.

![Иллюстрация из описания компонента](01)

В списках активная область чекбокса вытягивается на всю высоту строки.

![Иллюстрация из описания компонента](02)

## Название группы

Пишите название чекбокса с заглавной буквы.

Формулируйте название чекбокса в положительном ключе. Отрицательное название создаёт двойное отрицание: чтобы снять чекбокс «Не получать уведомления», пользователь читает его как «Не не получать уведомления».

![Иллюстрация из описания компонента](03)

Если пользователю может быть непонятно, что произойдёт при включении чекбокса, поясните это дополнительным текстом.

![Иллюстрация из описания компонента](04)

Либо используйте группу радиокнопок

![Иллюстрация из описания компонента](05)

Не вставляйте в название чекбокса ссылку: название само по себе интерактивный элемент. Если ссылка всё-таки нужна, оставьте первые 1 — 2 слова обычным текстом.

![Иллюстрация из описания компонента](06)

## Расположение

Обычно группу чекбоксов располагают в один столбец. В списке, размещённом горизонтально или в несколько столбцов, тяжелее ориентироваться: не всегда видна граница группы.

![Иллюстрация из описания компонента](07)

![Иллюстрация из описания компонента](08)

Разбивать чекбоксы на несколько столбцов можно, если разделение логично и понятно пользователю.

![Иллюстрация из описания компонента](09)

![Иллюстрация из описания компонента](10)

Если чекбокс связан по смыслу с другим элементом, сгруппируйте их.

![Иллюстрация из описания компонента](11)

## Валидация

Заблокируйте варианты, которые нельзя выбрать. Валидация возможна, только если пользователь обязан выбрать хотя бы один вариант.

Текст валидации располагайте под группой чекбоксов.

![Иллюстрация из описания компонента](12)

Тултип валидации появляется при наведении на группу чекбоксов.

![Иллюстрация из описания компонента](13)

Если система догадывается, что пользователь мог ошибиться, его можно предупредить.

![Иллюстрация из описания компонента](14)
