# Радиокнопки

Группа радиокнопок нужна, чтобы выбрать одно значение из нескольких.

## Когда использовать

Группу радиокнопок используют, когда вариантов выбора немного — 2 — 5.

Если вариантов 5 — 25, используйте раскрывающийся список.

Если больше 25 — комбобокс.

## Описание работы

Радиокнопка выбирается кликом по ней или по названию. Повторный клик не снимает выбор.

В группе радиокнопок можно выбрать только один пункт.

![Иллюстрация из описания компонента](01)

Группа радиокнопок не может состоять из одного пункта. Если вариант один, используйте свитч или чекбокс.

![Иллюстрация из описания компонента](02)

Если группа радиокнопок настраивает параметры и показывает текущее состояние системы, одна из радиокнопок всегда выбрана — так видно состояние по умолчанию. Пункт, выбранный по умолчанию, ставьте первым в списке.

## Название группы

Пишите название группы радиокнопок с заглавной буквы и формулируйте так, чтобы:
- было понятно, что можно выбрать только один вариант;
- названия радиокнопок в группе не содержали повторяющуюся часть.

![Иллюстрация из описания компонента](03)

## Название радиокнопки

Пишите название радиокнопки с заглавной буквы и формулируйте так, чтобы оно отвечало на вопрос «Как?» или «Какой?» / «Какая?».

Если пользователю может быть непонятно, что произойдёт при выборе, поясните это дополнительным текстом.

![Иллюстрация из описания компонента](04)

## Расположение

Располагайте радиокнопки в строку, только если их две или три. Если больше — только в столбец.

![Иллюстрация из описания компонента](05)

Не разбивайте одну группу радиокнопок на несколько столбцов: столбцы смешиваются, и непонятно, к чему относится радиокнопка.

![Иллюстрация из описания компонента](06)

![Иллюстрация из описания компонента](07)

## Валидация

Заблокируйте варианты, которые нельзя выбрать. Валидация возможна, только если пользователь обязан выбрать хотя бы один вариант.

Текст валидации располагайте под группой радиокнопок.

![Иллюстрация из описания компонента](08)

Тултип валидации появляется при наведении на группу радиокнопок.

![Иллюстрация из описания компонента](09)

Если система догадывается, что пользователь мог ошибиться, его можно предупредить.
