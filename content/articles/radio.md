# Радиокнопки

Группа радиокнопок нужна для выбора одного значения из нескольких.

## Когда использовать

Используйте радиокнопки для небольшого числа вариантов. Для более длинного списка подходят [select](/docs/select/) или [комбобокс](/docs/combobox/).

## Описание работы

Радиокнопка выбирается нажатием на неё или название. Повторное нажатие не снимает выбор. В группе можно выбрать только один пункт.

![В группе выбран только один вариант.](01)

Группа не может состоять из одного пункта. Для одного параметра используйте [свитч](/docs/switch/) или [чекбокс](/docs/checkbox/).

![Одиночную радиокнопку заменяет чекбокс.](02)

Если группа настраивает параметры и показывает текущее состояние системы, одна радиокнопка всегда выбрана. Ставьте выбранный по умолчанию пункт первым.

## Название группы

Пишите название с заглавной буквы. Из него должно быть понятно, что можно выбрать один вариант. Выносите повторяющуюся часть из названий пунктов в название группы.

![Общая часть «Уведомлять один раз в» вынесена в название группы.](03)

## Название радиокнопки

Пишите название с заглавной буквы. Формулировка отвечает на вопрос «Как?» или «Какой? / Какая?».

Если последствия выбора неочевидны, добавьте пояснение.

![Дополнительные пояснения к вариантам выбора.](04)

## Расположение

Два или три варианта можно расположить в строку. Если их больше, используйте столбец.

![Два варианта можно расположить вертикально или горизонтально.](05)

Не разбивайте одну группу на несколько столбцов: они смешиваются, и принадлежность радиокнопок становится неясной.

![Неудачное размещение одной группы в нескольких столбцах.](06)

![Все варианты одной группы в одном столбце.](07)

## Валидация

Блокируйте варианты, которые нельзя выбрать. Проверка нужна только при обязательном выборе. Текст ошибки располагается под группой.

![Ошибка под группой радиокнопок.](08)

Тултип появляется при наведении на группу.

![Тултип валидации над группой.](09)

Если система предполагает возможную ошибку, можно показать предупреждение.

![Предупреждение о последствиях отсутствия выбора способа получения.](10)
