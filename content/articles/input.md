# Поле ввода

Для коротких текстовых или цифровых значений без предсказуемого формата.

## Название

Пишите название с заглавной буквы. Называйте поле существительным, которое указывает, что нужно ввести. Избегайте слов «ваш», «введите» и подобных: они не добавляют смысла.

## Описание работы

### Плейсхолдер

Если из названия неочевидно, как заполнить поле, используйте плейсхолдер — подсказку внутри пустого поля.

![Пустое поле с плейсхолдером «Подсказка».](01)

При фокусе плейсхолдер становится светлее, а после ввода первого символа исчезает.

![Поле в покое, в фокусе и после начала ввода.](02)

Не указывайте в плейсхолдере конкретное значение, которое нужно ввести. Лучше предзаполните поле: если предположение окажется неверным, пользователь исправит значение.

![Плейсхолдер «Бухгалтер» и поле с заранее заполненным значением.](03)

Для формата и ограничений используйте [поле с маской](/docs/mask/), а не плейсхолдер.

![Подсказка «9 цифр» и маска для КПП.](04)

Не заменяйте плейсхолдером название: после заполнения пользователь может забыть, что вводит.

![Поля с исчезающими названиями и поля с постоянными подписями.](05)

Исключение — необходимость сэкономить место или обозначить конкретное поле в группе.

![Группа «ФИО» с подсказками «Фамилия», «Имя», «Отчество».](06)

### Очистка поля

Если пользователю часто нужно очищать поле и вводить новое значение, добавьте кнопку-крестик. По умолчанию её нет.

![Крестик для очистки заполненного поля.](07)

Если справа есть иконка, крестик заменяет её. Крестик появляется после ввода хотя бы одного символа и исчезает в пустом поле.

![Заполненное поле с крестиком и пустое поле без него.](08)

Если полей много, показывайте крестики при наведении и фокусе, чтобы избежать визуального шума.

![Крестики во всех полях и только в активном поле.](09)

Если поле одно, показывайте крестик постоянно при непустом значении: пользователю будет удобнее целиться.

![Крестик в одиночном поле поиска.](10)

После нажатия крестика значение стирается, фокус переходит в поле.

![Очистка поля с возвращением фокуса.](11)

При наведении иконка становится темнее. Область нажатия по высоте равна полю.

![Изменение цвета крестика при наведении.](12)

![Область нажатия крестика на всю высоту поля.](13)

## Валидация

Правила проверки значений описаны в статье [«Валидация»](/docs/validation/).

## Дизайн

По умолчанию радиус скругления — 8 px, рамка — цвета Cool Gray 2. Это подходит для большинства случаев, особенно для форм с большим количеством полей.

Небольшая настройка внешнего вида может помочь:

- привлечь внимание к главному сценарию;
- согласовать поле с соседними контролами;
- компенсировать остроугольность других элементов страницы.
