# Поле ввода

Для коротких текстовых или цифровых значений без предсказуемого формата.

## Название

Название поля пишется с заглавной буквы. Называйте поле ввода существительным, которое указывает, что нужно ввести. Избегайте в названии слов «ваш», «введите» и подобных — они не несут смысла.

## Описание работы

### Плейсхолдер

Если из названия неочевидно, как заполнять поле, используйте плейсхолдер — подсказку, которая отображается внутри поля, пока оно не заполнено.

![Иллюстрация из описания компонента](01)

По фокусу плейсхолдер становится светлее, а при вводе первого символа исчезает.

![Иллюстрация из описания компонента](02)

Не пишите в плейсхолдере конкретное значение, которое нужно ввести в поле. Лучше предзаполните его. Если ошибётесь, пользователь исправит.

![Иллюстрация из описания компонента](03)

Не используйте плейсхолдер для указания формата и ограничений. Используйте поле с маской

![Иллюстрация из описания компонента](04)

Не используйте плейсхолдер для названия. В заполненном состоянии такая форма становится «слепой» — легко забыть, какое поле ты заполняешь.

![Иллюстрация из описания компонента](05)

Исключение — когда нужно сэкономить место или указать на конкретное поле из группы полей.

![Иллюстрация из описания компонента](06)

### Очистка поля

Если пользователю нужно часто очищать поле и вводить новое значение — используйте кнопку-крестик для очистки. По умолчанию, крестика в поле нет.

![Иллюстрация из описания компонента](07)

Если справа есть иконка, то крестик заменит ее

Крестик показывается, когда введён хотя бы 1 символ, и пропадает, когда поле пустое.

![Иллюстрация из описания компонента](08)

Когда на странице много полей с крестиками, показывайте их и по ховеру, и по фокусу. Чтобы не создавалось визуального шума.

![Иллюстрация из описания компонента](09)

А когда поле одно, показывайте крестик всегда. Так пользователю будет удобнее целиться.

![Иллюстрация из описания компонента](10)

При клике на крестик фокус переходит в поле, введённое значение стирается.

![Иллюстрация из описания компонента](11)

При наведении иконка становится темнее

![Иллюстрация из описания компонента](12)

Область нажатия по высоте равна полю ввода.

![Иллюстрация из описания компонента](13)

## Дизайн

По умолчанию радиус скругления углов 8px и рамка цвета Cool Gray 2. Такой дизайн хорошо смотрится в большинстве случаев, особенно в формах с большим количеством полей.

Есть ситуации, когда небольшая кастомизация улучшает внешний вид. Типичные примеры:
- привлечь внимание к главному сценарию,
- синхронизировать внешний вид с контролами рядом,
- компенсировать остроугольность других элементов страницы.
