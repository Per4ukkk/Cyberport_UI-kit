# Комбобокс

Комбобокс — это поле ввода со списком подсказок.

## Когда использовать

Комбобокс используют:
- для выбора значения из справочника,
- для добавления своего значения в справочник

Используйте комбобокс, если значений в справочнике слишком много, чтобы искать их глазами. Если значений не больше 25, можно использовать раскрывающийся список или группу радиокнопок

Комбобокс может работать в двух режимах — обычном и в режиме автокомплита

### Обычный режим — комбобокс со стрелкой

![Иллюстрация из описания компонента](01-left)

Поле работает по аналогии с раскрывающимся списком — при клике в поле сразу появляется список всех вариантов. Об этом подсказывает стрелка и плейсхолдер.

Используйте этот режим, если вы точно знаете, что справочник не будет содержать больше 50 строк, либо уверены, что пользователю удобней выбирать значение, просматривая список.

### Автокомплит — комбобокс без стрелки

![Иллюстрация из описания компонента](01-right)

Список вариантов появляется только после ввода первого символа. Поэтому в поле нет стрелки, а плейсхолдер подсказывает, что достаточно ввести первые буквы.

Используйте это поле, если в справочнике больше 50 строк или пользователь привык заполнять подобные поля, вводя значения с клавиатуры.

## Описание работы

### Комбобокс со стрелкой

Плейсхолдер подсказывает, что в поле можно ввести своё значение или выбрать его из списка вручную.

![Иллюстрация из описания компонента](02)

При фокусе плейсхолдер становится чуть светлее, открывается список вариантов

![Иллюстрация из описания компонента](03)

Когда курсор находится на списке, скроллинг страницы блокируется.

При вводе первого символа список фильтруется. Первый пункт в списке подсвечивается.

![Иллюстрация из описания компонента](04)

Выбор значения может быть сделан двумя способами — при управлении с клавиатуры и мышью

При выборе значения мышью или клавишей Enter список закрывается, фокус остаётся в поле. Список будет показан снова при следующем клике в поле или изменении значения.

![Иллюстрация из описания компонента](05)

При фокусе введённое значение выделяется, раскрывается список и скроллится до выбранного значения.

![Иллюстрация из описания компонента](06)

Если в справочнике не найдено совпадений с введённым значением, комбобокс показывает соответствующий текст. Важно показать подсказку, чтобы пользователь понял, что поле обработало его запрос.

![Иллюстрация из описания компонента](07)

В этом состоянии при нажатии на клавиатуре Enter ничего не происходит, фокус остаётся в поле.

Если введённое значение совпадает со значением из справочника, при потере фокуса это значение выбирается.

![Иллюстрация из описания компонента](08)

Если ничего не нашлось, покажите ошибку.

![Иллюстрация из описания компонента](09)

### Комбобокс без стрелки

Комбобокс в режиме автокомплита, то есть комбобокс без стрелки, работает так же, как со стрелкой, но с некоторыми исключениями.

![Иллюстрация из описания компонента](10)

Чтобы заполнить такое поле, пользователь должен помнить первые буквы нужного значения. Поиск запускается и появляется список вариантов только после ввода первого символа. В поле нет стрелки, а плейсхолдер подсказывает, что достаточно ввести первые буквы.

![Иллюстрация из описания компонента](11)

Оптимальное количество строк в списке — 5. Если после фильтрации список может быть очень большим, это число можно увеличивать до 20.

## Варианты использования

### Составной список

Если у каждой записи справочника есть несколько параметров, показывайте в списке самые важные. По ним работает поиск.

Основное значение — короткое, ёмкое и уникальное.

![Иллюстрация из описания компонента](12)

После того как выбор сделан, показывайте дополнительное значение в поле серым цветом, если это возможно

![Иллюстрация из описания компонента](13)

Если оно полностью не входит, показывайте при наведении хинт.

![Иллюстрация из описания компонента](14)

При фокусе тултип исчезает.

![Иллюстрация из описания компонента](15)

### Избранные варианты

Если это уместно, предлагайте пользователю наиболее вероятные варианты ещё до начала ввода. Например, определение города по геопозиции или ip.

![Иллюстрация из описания компонента](16)

Если это комбобокс в режиме автокомплита, сразу по фокусу показывайте список из 3 — 5 вариантов с заголовком. Заголовок нужен, чтобы было понятно, что это не полный список.

![Иллюстрация из описания компонента](17)

## Справочники

### Значение не из справочника

Если справочник может быть неактуальным, дайте пользователю возможность указать своё значение. При этом значение пользователя не добавляется в справочник, а на странице выводится предупреждение, чтобы обратить внимание пользователя на возможную ошибку.

![Иллюстрация из описания компонента](18)

### Автоматическое добавление в справочник

Если пользователь сам наполняет справочник, а каждая запись имеет дополнительный набор полей, показывайте пункт «Добавить» внизу списка, чтобы пользователь мог быстро перейти к добавлению новой карточки.

![Иллюстрация из описания компонента](19)

Прежде чем добавлять новую карточку, пользователь, скорее всего, захочет проверить, что такой ещё нет в списке. Он начнёт набирать текст в комбобоксе, и если не будет совпадений — последний пункт «Добавить» подсветится автоматически.

![Иллюстрация из описания компонента](20)

Если в предыдущем состоянии поле теряет фокус, срабатывает валидация: поле красится в красный, показывается сообщение об ошибке.

![Иллюстрация из описания компонента](21)

## Спиннер

Если обработка запроса для построения списка занимает дольше 0,3 секунды, показываем спиннер минимум 1 секунду.

Лоадер серый, не привлекающий слишком много внимания

![Иллюстрация из описания компонента](22)

Если происходит ошибка сервера, показываем сообщение.

![Иллюстрация из описания компонента](23)

Нажатие Enter при пустом/незагрузившемся списке ни к чему не приводит, фокус остаётся в этом же поле.

## Управление клавиатурой

При клике по полю и при переходе табом поле выглядит одинаково: появляется синяя рамка, которая сохраняется до потери фокуса.

**Tab**

Переход к следующему контролу.

**↓ ↑**

Если открыт список вариантов из нескольких значений — переключение между строками. Переход между строками не цикличен — с последней строки фокус не переходит на первую, как и с первой на последнюю.

Если список скрыт, содержит только один вариант, сообщение об ошибке или о том, что нет совпадений, то текстовый курсор стоит в начале или в конце строки.

**→ ←**

Перемещение текстового курсора в поле ввода

**Esc**

Скрывает список, фокус не исчезает. Список появится вновь при вводе или удалении символа.

**Space**

Ввод пробела

**Enter**

Выбор подсвеченного значения из списка и переход к следующему полю в форме. Если список пуст/не успел догрузиться, нажатие Enter ни к чему не приводит.
