# Поле с телефоном

Специальное поле, упрощающее ввод телефонного номера.

## Когда использовать

Используйте специальное поле для ввода телефона, когда нужен номер в полном формате.

![Иллюстрация из описания компонента](01)

Для ввода номеров телефона без форматирования можно использовать обычное поле ввода.

![Иллюстрация из описания компонента](02)

## Описание работы

Поле с телефоном — это частный случай поля с маской, с двумя отличиями:

1. В начале поля стоит префикс «+7», который подсказывает пользователю, что номер нужно ввести в полном формате. Префикс нельзя стереть.

![Иллюстрация из описания компонента](03)

2. При вставке скопированного номера из 11 цифр первые +7 или 8 вырезаются.
