# Свитч

Свитч переключает состояния.

## Когда использовать

Свитч — аналог чекбокса, но контексты использования у них разные.

Используйте свитч, чтобы включать и выключать настройки — например, уведомления или отправку отчётов.

Свитчем нельзя выбирать элементы в списке, например несколько строк. Для этого используйте чекбокс.

Свитч больше и заметнее чекбокса, поэтому хорошо, когда на странице он 1, максимум 2 — 3.

## Описание работы

Свитч переключается кликом по нему или по названию.

![Иллюстрация из описания компонента](01)

При переключении эффект наступает сразу, поэтому свитчу не нужна кнопка «Сохранить».

## Название

Пишите название свитча с заглавной буквы.

Не используйте в названии глаголы «Включить» и «Выключить» — этот смысл уже заложен в метафору контрола.

![Иллюстрация из описания компонента](02)

Формулируйте название свитча в положительном ключе. Отрицательное название создаёт двойное отрицание: чтобы выключить тогл «Не отправлять отчёты», пользователь читает его как «Не не отправлять отчёты».

![Иллюстрация из описания компонента](03)

Не меняйте название при переключении: подпись остаётся одной и той же в обоих состояниях.

![Иллюстрация из описания компонента](04)

Не используйте вопросительные формулировки.

![Иллюстрация из описания компонента](05)

Если пользователю может быть непонятно, что произойдёт при включении тогла, поясните это дополнительным текстом.

![Иллюстрация из описания компонента](06)

Название свитча может занимать несколько строк.

![Иллюстрация из описания компонента](07)
