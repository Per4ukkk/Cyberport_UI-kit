# Select

В раскрывающемся списке (селекте) можно выбрать значение из заранее известного набора вариантов.

## Когда использовать

Используйте селект для выбора одного значения из 5 — 25 вариантов:
- заполнение форм, например, выбор месяца;
- переключение состояний, например, фильтры;
- выбор предустановленных настроек, например, частота уведомлений или часовой пояс.

Если значений в списке до 5, лучше использовать группу радиокнопок. Если значений больше 25 — используйте комбобокс

## Описание работы

При нажатии на селект появляется список вариантов для выбора. После выбора одного из вариантов его название подставляется в селект, список скрывается, размеры селекта при этом остаются прежними.

![Иллюстрация из описания компонента](01)

Список вариантов открывается поверх остального интерфейса, не блокирует страницу и не мешает пользователю нажимать на другие контролы. Список скрывается при клике за его пределами и при повторном клике по селекту. В этом случае значение селекта не меняется.

Если селект используется для настройки параметров, в нём сразу выбрано значение, соответствующее текущему состоянию системы. Это даёт пользователю возможность вернуть настройку в первоначальное состояние.

![Иллюстрация из описания компонента](02)

Если невозможно выбрать значение за пользователя, то поле остаётся пустым или с плейсхолдером-призывом к заполнению — например, «Выберите». В списке вариантов плейсхолдер не показывается.

![Иллюстрация из описания компонента](03)

Чтобы пользователь мог отменить выбор, добавьте в список соответствующий пункт. Например, «Все», «Любой», «Неважно». Отделите такой пункт линией.

![Иллюстрация из описания компонента](04)

Скролл в раскрывающемся списке должен блокировать скролл всей страницы, пока указатель мышки находится внутри блока. Если этого не сделать, страница проскроллится при достижении верхней или нижней границы.

## Название

Названия селекта и вариантов пишутся с заглавной буквы и формулируются так, чтобы:
- было понятно, что можно выбрать только 1 вариант;
- названия не содержали повторяющуюся часть;
- название селекта не дублировалось в вариантах списка.

![Иллюстрация из описания компонента](05)

В подписи к селекту нельзя писать слова «Выберите», «Укажите» и т. д.

![Иллюстрация из описания компонента](06)

## Размер и расположение

Ширина кнопки должна быть такой, чтобы большая часть значений из списка помещалась полностью:

![Иллюстрация из описания компонента](07)

Если выбранное значение не помещается, появляется многоточие:

![Иллюстрация из описания компонента](08)

Раскрывающийся список не может быть меньше селекта по ширине.

![Иллюстрация из описания компонента](09)

Красиво, когда список шире селекта на 24 — 40 px.

![Иллюстрация из описания компонента](10)

Названия пунктов не обрезаются и показываются полностью, при необходимости переносятся на несколько строк.

![Иллюстрация из описания компонента](11)

Элементы списка расположены в один столбец в соответствии с логикой, понятной пользователю. Например: отсортированы по алфавиту, по номеру.

В больших списках полезно продублировать популярные варианты в начале списка, отделив их линией.

Обычно список раскрывается вниз. Минимальная высота списка со скроллингом — 6 элементов. При наличии места список стремится отобразить максимум вариантов и расширяется до высоты 10 элементов.

Исключение — если раскрывающийся список находится у нижней границы окна. В таком случае он открывается вверх.

## Валидация

Блокируйте или убирайте из списка варианты, выбор которых приведёт к ошибке. Таким образом, валидация понадобится только для проверки на обязательность выбора.
