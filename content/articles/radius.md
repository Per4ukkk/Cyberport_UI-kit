# Скругления

Большинство элементов интерфейса CyberPort имеют скругления. В основном это:

— Основное — 8 px — для большинства элементов

— Увеличенное — 12 px — для больших блоков

Также можно встретить:

— Маленькое — 4 px — для маленьких элементов: кнопки, обводки иконок и пр.

— Большое — 20 px — для очень больших блоков, в основном на "воздушных" страницах, где визуал важнее чем функциональность

Этих значений хватит для подавляющего большинства макетов, дизайнеры CyberPort стараются не использовать другие.

Но в некоторых случаях этих значений может не хватить. Тогда допустимо использовать другие числа из шкалы отступов: 2 px, 6 px, 4*X px (кратное модулю)

## Нюансы

### Круглые блоки

Блоки не должны быть слишком узкими, например, блок со скруглениями 16 px не может быть высотой 32 px, только 48 px и больше.

![Иллюстрация из описания компонента](01)

Универсальное правило: Блок со скруглением X не может быть высотой или шириной меньше чем 3X.

### Согласованность скруглений

Это касается ситуаций, когда один элемент со скруглением находится внутри другого.

Скругления согласованы если ширина промежутка между элементами одинакова по всему периметру.

![Иллюстрация из описания компонента](02)

Чтобы этого достичь, нужно воспользоваться формулой: Внешнее скругление = Внутреннее + Боковой отступ
