# Скругления

Большинство элементов интерфейса CyberPort имеют скругления.

## Основные значения

- **8 px** — основное, для большинства элементов.
- **12 px** — увеличенное, для больших блоков.
- **4 px** — маленькое, для небольших элементов: кнопок, обводок иконок и подобных.
- **20 px** — большое, для очень крупных блоков, преимущественно на «воздушных» страницах, где визуальная часть особенно важна.

Этих значений хватает для большинства макетов. Если их недостаточно, допустимы другие числа из шкалы отступов, в том числе 2 px и 6 px.

## Круглые блоки

Блок не должен быть слишком узким. Например, при радиусе 16 px его высота не может быть 32 px: нужна высота 48 px или больше.

![Блок с радиусом 16 px: недостаточная и подходящая высота.](01)

Универсальное правило из описания: высота и ширина блока с радиусом X не меньше 3X.

## Согласованность скруглений

Когда один скруглённый элемент находится внутри другого, промежуток между ними должен выглядеть одинаковым по всему периметру.

![Несогласованные и согласованные скругления вложенных блоков.](02)

Для этого используйте формулу: **внешний радиус = внутренний радиус + боковой отступ**.
