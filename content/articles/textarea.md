# Многострочное поле

Многострочное поле — это поле ввода, в котором текст отображается в несколько строк.

## Когда использовать

Используйте многострочное поле, если пользователю нужно ввести много слов. Если значение чаще всего состоит из 1 — 3 слов, следует использовать обычное поле ввода

## Название

Требования к названию многострочного поля такие же, как и к однострочного. Если назначение многострочного поля очевидно, то назваие можно разместить внутри поля в виде плейсхолдера:

![Иллюстрация из описания компонента](01)

## Описание работы

По мере ввода высота поля автоматически увеличивается и уменьшается так, что всегда свободна одна строка. Это нужно, чтобы пользователь видел весь текст без скролла, и при этом по умолчанию поле было бы не очень высоким.

![Иллюстрация из описания компонента](02)

Любому такому полю нужно задать максимальную высоту чтобы оно не занимало слишком много места на экране. Старайтесь ограничивать эту высоту так, чтобы поле в формах полностью оставалось на экране.

При достижении максимальной высоты поле перестает расти и появляется скролл-бар

## Счётчик введённых символов

Если есть ограничение по количеству символов и есть большая вероятность, что пользователь его превысит, — включите счётчик символов. Он поможет пользователю подстроиться под ограничение.

### Форматирование текста

Если ограничение неочевидное, сделайте подсказку. Наведение на иконку откроет тултип.

Для многострочного поля предусмотрена возможность форматирования текста. На данный момент доступны:
- Жирный
- Курсив
- Подчеркнутый
- Списки (пронумерованный и нет)
- Ссылки

Меню выбора форматирования вызывается при выделении соответствующего текста. Появляется над текстом если позволяет пространство, иначе под ним. Расстояние между выделенной строчкой и меню - 2 модуля (8px)

![Иллюстрация из описания компонента](09)

## Размер и расположение

Минимальная высота многострочного поля ввода — 3 строки, чтобы пользователю было понятно, что это не обычное поле ввода и можно вводить большой текст. Если в форме много таких полей, можно ради экономии пространства уменьшить высоту каждого поля до 2 строк.

![Иллюстрация из описания компонента](10)

Правильно задавать высоту поля через количество строк. Неправильно задавать высоту через высоту поля в пикселях, потому что при изменении размера шрифта средствами браузера высота поля не увеличится, и им будет неудобно пользоваться.

Ширина поля должна быть в пределах 30 — 80 символов, то есть около 250 — 600 px. Узким полем неудобно пользоваться из-за частого переноса строк. Широкое поле допустимо только в WYSIWYG-редакторе (What You See Is What You Get).
