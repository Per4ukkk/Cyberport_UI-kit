# Поле с токенами

Поле ввода со списком подсказок для нескольких однородных элементов — токенов. Похоже на [комбобокс](/docs/combobox/).

## Когда использовать

Для выбора нескольких значений из справочника и добавления своих значений.

## Название

Используйте множественное число: поле допускает несколько значений.

![Название во множественном числе: «Введите или выберите домены».](01)

## Выбор из справочника

При нажатии на элемент его чекбокс становится выбранным, а элемент перемещается в начало списка.

![Выбор города и перемещение выбранного элемента наверх.](02)

Во время поиска выбранный токен в поле не отображается: пользователь может продолжать искать другие значения.

После потери фокуса поле показывает выбранные значения. Не поместившиеся скрываются за «+N». Порядок токенов совпадает с порядком списка. Если не помещается первое значение, оно обрезается многоточием.

![После потери фокуса показаны токен «Абакан» и ещё два выбранных значения.](03)

Крестик удаляет токен без открытия справочника.

![Удаление токена «Абакан» крестиком.](04)

Нажатие «+N» открывает справочник.

![Открытие списка выбранных городов через «+2».](05)

## Добавление в справочник

Если можно вводить любые значения, в конце списка появляется пункт «Добавить своё значение».

После выбора этого пункта и ввода в появившееся поле значение добавляется и в справочник, и в поле.
