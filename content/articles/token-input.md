# Поле с токенами

Поле с токенами — это поле ввода со списком подсказок, используется в случаях, когда нужно указать сразу много однородных элементов — токенов Оно похоже на комбобокс

## Когда использовать

Поле с токенами используют для выбора нескольких значений из справочника и для добавления своих значений.

## Название

Используйте множественное число при указании названия — поле с токенами допускает ввод нескольких значений.

![Иллюстрация из описания компонента](01)

## Виды полей

### С выбором из справочника

Для добавления значений нужно нажать на элемент в справочнике, при этом чекбокс загорится выбранным и элемент перенесется наверх списка.

![Иллюстрация из описания компонента](02)

Но в самом поле чекбокс не отобразится, это нужно чтобы пользователь мог искать значения после того как уже что-то выбрал

При потере фокуса в поле отображаются выбранные значения. Те, что не влезли, прячутся за "+N". Порядок токенов внутри поля совпадает с порядком в списке. Если не влезает первое по порядку значение то название обрезается тремя точками.

![Иллюстрация из описания компонента](03)

При нажатии на крестик внутри поля токен удаляется без открытия справочника

![Иллюстрация из описания компонента](04)

При нажатии на "+N", открывается справочник

![Иллюстрация из описания компонента](05)

### С возможностью добавления в справочник

Если пользователь может вводить любые значения в поле, в конце списка появляется кнопка «Добавить свое значение»

Значение добавляется в справочник и в поле, если выбрать этот пункт в списке и ввести свое значение в появившееся поле
