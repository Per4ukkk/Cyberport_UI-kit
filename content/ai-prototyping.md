# Кликабельные прототипы Cyberport

## Назначение материалов

Исходники на витрине — экспериментальный код только для кликабельных прототипов. Рабочая React-библиотека компании находится во внутреннем Storybook и здесь пока не представлена. Этот код не описывает её API и не является инструкцией по подключению компонентов в рабочий продукт.

Авторские правила UI-kit и утверждённые чек-листы доступны отдельно. Технические особенности экспериментального кода не вводят новых требований к дизайн-ревью.

## С чего начать

1. Прочитай /ai/manifest.json, /ai/guide.md и /ai/context.md.
2. Для нужных компонентов открой документы из components[].markdown, их исходники из sourceFiles и сведения об ограничениях. Дополнительные параметры доступны и тогда, когда они не включены в верхнем примере страницы.
3. Полный комплект для прототипа: /downloads/cyberport-ui-kit.zip. Сохрани ui-kit/, fonts/ и icons/ рядом. Подключи ui-kit/index.css и импортируй нужные фабрики из ui-kit/index.js. START.html показывает минимальный пример; README.md содержит назначение и запуск.
4. Код использует JavaScript ES Modules и DOM. Используй реальные фабрики и их параметры. React API, npm-пакет и обёртки корпоративной библиотеки в этих материалах отсутствуют.
5. Полный пак иконок: /icon-library/index.json. Инструкция: /icon-library/README.md; текстовый каталог: /icon-library/index.md; отдельный архив: /downloads/cyberport-icons.zip. Все SVG также входят в полный комплект прототипа. Выбирай по name, style и размеру; бери файл по url или по file относительно icons/index.json в архиве. Не выдумывай имя для cpIcon: встроенный набор фабрик ограничен их исходным кодом, остальные SVG подключай напрямую.

## Сценарий 1. Бизнес-требования

Определи роли пользователей, основную задачу, экраны, переходы и необходимые состояния по приложенным требованиям. Используй правила UI-kit при сборке интерфейса. Существенные пробелы, которые мешают выбрать сценарий, уточни; остальные предположения перечисли явно. Не выдавай предположение за бизнес-требование. Подготовь кликабельный прототип на демонстрационных данных с переходами и обратной связью на основные действия.

## Сценарий 2. Макеты JSON + PNG

Сопоставь JSON и PNG каждого экрана. Используй доступные свойства и структуру JSON вместе с визуальным изображением: сохрани композицию, текст, размеры, отступы и состояния. Учитывай видимость необязательных элементов. Воспроизведи заданные переходы; если поведение не описано, перечисли предлагаемые допущения. Если источники противоречат друг другу, обозначь расхождение; критичные для реализации противоречия уточни. Не утверждай, что свойства, отсутствующие в материалах, были проверены.

## Результат

Создай запускаемый кликабельный прототип, а не только план. Проверь основной сценарий, переходы и интерактивные состояния. Дай понятную инструкцию запуска через HTTP-сервер, укажи версию материалов из манифеста, сделанные предположения и ограничения. Если источники недоступны или вложений недостаточно, сообщи об этом и запроси недостающие материалы; не утверждай, что прочитал их.
